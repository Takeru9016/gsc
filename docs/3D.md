# GSC — Animation & Motion Reference
# Replaces the original 3D/WebGL plan entirely.
# Stack: Video hero + Lottie sport animations + GSAP scroll experience.
# No WebGL. No React Three Fiber. No Three.js.

---

## What Changed and Why

Original plan used React Three Fiber (WebGL) for:
- Homepage hero particle scene
- Sports scroll 6-scene WebGL experience
- 3D sport objects on /sports/[slug] hero

Replaced with:
- Homepage hero → looping MP4 video background (existing GSC footage)
- Sports scroll → GSAP ScrollTrigger pinned CSS experience
- Sport hero → Lottie JSON animations (per sport category)

Reasons:
- 60–70% of Indian web traffic is mobile — WebGL was invisible to that audience
- WebGL adds 500KB+ to bundle, requires disposal patterns, breaks on low-end hardware
- Video and Lottie are fully mobile-compatible, lighter, and easier to maintain
- Real GSC footage is more emotionally resonant than any generated 3D scene

### Video Performance Rules
- **Compress before deploying** — target < 8MB for the hero MP4. Use ffmpeg:
  ```bash
  ffmpeg -i gsc-hero.mp4 -vcodec h264 -acodec aac -crf 28 -vf scale=1920:-1 gsc-hero-compressed.mp4
  ```
- **Always include `poster`** — a static JPG frame shown instantly while video loads. Export first frame from the video.
- **`playsInline`** is required for autoplay on iOS.
- **`muted`** is required for autoplay on all browsers — no exceptions.
- **`preload="none"`** is acceptable if you want to save bandwidth. Video starts loading on user interaction. `preload="metadata"` is the middle ground (loads first frame for poster). Default (`auto`) loads the whole thing — fine for < 8MB.
- **Mobile**: video autoplays on modern iOS/Android when `muted` + `playsInline`. No workaround needed.

### Fallback
If video fails to load (slow connection, network error), the poster image + dark overlay shows. The section is fully usable.

## Lottie Sport Animations

### What Lottie Is
Lottie plays After Effects animations as JSON. They're vector-based, tiny (20–200KB), and run at 60fps on all devices.

### Package
```bash
pnpm add lottie-react
```

### Files Needed
6 Lottie JSON files — one per sport category shown in the sports scroll:

| File                           | Sport       | Where used                                          |
| ------------------------------ | ----------- | --------------------------------------------------- |
| `public/lottie/cricket.json`   | Cricket     | Sports scroll Scene 1 + /sports/cricket-ground hero |
| `public/lottie/swimming.json`  | Swimming    | Sports scroll Scene 2 + /sports/swimming-pool hero  |
| `public/lottie/badminton.json` | Badminton   | Sports scroll Scene 3 + /sports/badminton hero      |
| `public/lottie/tennis.json`    | Tennis      | Sports scroll Scene 4 + /sports/lawn-tennis hero    |
| `public/lottie/squash.json`    | Squash      | Sports scroll Scene 5 + /sports/squash hero         |
| `public/lottie/gym.json`       | Gym/Fitness | Sports scroll Scene 6 + /sports/gym hero            |

### Sourcing Lottie Files
Three options in order of preference:

1. **LottieFiles marketplace** — lottiefiles.com. Search "cricket ball", "swimming", "badminton" etc. Free and premium files available. Download as JSON. Filter for sports/minimal/dark-compatible styles for visual consistency.

2. **Commission from graphic team** — if GSC's graphic team uses After Effects, they can export Lottie JSON from any animation. Consistent with brand colors.

3. **Fallback** — if no Lottie available for a sport, use a high-quality sport photograph with GSAP entrance animation. Never show a broken component.

### Implementation

```tsx
// components/shared/LottiePlayer.tsx
'use client'
import Lottie from 'lottie-react'

interface LottiePlayerProps {
  src: object           // imported JSON
  className?: string
  loop?: boolean        // default true
  autoplay?: boolean    // default true
  speed?: number        // default 1
}

export function LottiePlayer({
  src,
  className,
  loop = true,
  autoplay = true,
  speed = 1,
}: LottiePlayerProps) {
  return (
    <Lottie
      animationData={src}
      loop={loop}
      autoplay={autoplay}
      className={className}
      style={{ width: '100%', height: '100%' }}
      rendererSettings={{ preserveAspectRatio: 'xMidYMid slice' }}
    />
  )
}
```

## Sports Scroll — GSAP CSS Experience

### Overview
- GSAP ScrollTrigger **pins** the sports section
- 6 full-viewport panels, each revealed on scroll
- Sport photography background per panel (from Sanity sport.heroImage)
- Large sport name typography + stat counter per panel
- Lottie animation plays in corner of each panel (desktop)
- Progress dots: fixed right side, 1–6
- Fully mobile-compatible — same component, no fallback needed

### Implementation

```tsx
// components/sections/sports/SportsScroll.tsx
'use client'
import { useEffect, useRef } from 'react'
import { gsap } from 'gsap'
import { ScrollTrigger } from 'gsap/ScrollTrigger'

gsap.registerPlugin(ScrollTrigger)

const SPORT_SCENES = [
  { name: 'Cricket', count: '3 formats', color: '#FFB300', lottie: 'cricket' },
  { name: 'Swimming', count: 'Olympic pool', color: '#1E88E5', lottie: 'swimming' },
  { name: 'Badminton', count: '12 courts', color: '#F9FAFB', lottie: 'badminton' },
  { name: 'Lawn Tennis', count: '4 courts', color: '#E8A020', lottie: 'tennis' },
  { name: 'Squash', count: '4 courts', color: '#9333EA', lottie: 'squash' },
  { name: 'Health Club', count: '3 centres', color: '#E53935', lottie: 'gym' },
]

export function SportsScroll({ sports }: { sports: SportQuery[] }) {
  const containerRef = useRef<HTMLDivElement>(null)
  const panelsRef = useRef<HTMLDivElement[]>([])

  useEffect(() => {
    if (!containerRef.current) return

    // Pin the container, scroll through all 6 panels
    const panels = panelsRef.current
    const totalWidth = panels.length * window.innerWidth

    const ctx = gsap.context(() => {
      // Horizontal scroll approach — panels slide left on scroll
      gsap.to(panels, {
        xPercent: -100 * (panels.length - 1),
        ease: 'none',
        scrollTrigger: {
          trigger: containerRef.current,
          pin: true,
          scrub: 1,
          end: () => `+=${totalWidth}`,
          snap: 1 / (panels.length - 1),
          onUpdate: (self) => {
            // Update active dot
            const activeIndex = Math.round(self.progress * (panels.length - 1))
            document.querySelectorAll('.scroll-dot').forEach((dot, i) => {
              dot.classList.toggle('active', i === activeIndex)
            })
          },
        },
      })

      // Animate text within each panel as it enters
      panels.forEach((panel) => {
        gsap.from(panel.querySelector('.panel-headline'), {
          y: 40,
          opacity: 0,
          duration: 0.6,
          scrollTrigger: {
            trigger: panel,
            containerAnimation: ScrollTrigger.getAll()[0],
            start: 'left center',
            once: true,
          },
        })
      })
    }, containerRef)

    return () => ctx.revert()
  }, [])

  return (
    <div className="relative">
      {/* Progress dots — fixed right side */}
      <div className="fixed right-6 top-1/2 -translate-y-1/2 z-50 flex flex-col gap-3">
        {SPORT_SCENES.map((_, i) => (
          <div key={i} className="scroll-dot w-2 h-2 rounded-full border border-white/50 transition-all duration-300 [&.active]:bg-white [&.active]:scale-125" />
        ))}
      </div>

      {/* Pinned container */}
      <div ref={containerRef} className="flex overflow-hidden">
        {SPORT_SCENES.map((scene, i) => {
          const sport = sports.find(s => s.name.toLowerCase().includes(scene.name.toLowerCase().split(' ')[0]))
          return (
            <div
              key={scene.name}
              ref={el => { if (el) panelsRef.current[i] = el }}
              className="min-w-full h-screen relative flex items-center"
              data-theme="dark"
            >
              {/* Sport background image */}
              {sport?.heroImage && (
                <div className="absolute inset-0">
                  <Image src={urlFor(sport.heroImage).width(1920).url()} fill className="object-cover" alt={scene.name} />
                  <div className="absolute inset-0 bg-[--color-bg-dark]/70" />
                </div>
              )}

              {/* Content */}
              <div className="relative z-10 max-w-7xl mx-auto px-8 grid grid-cols-2 items-center gap-12 w-full">
                <div>
                  <p className="panel-headline font-body text-sm tracking-widest uppercase mb-4" style={{ color: scene.color }}>
                    {`0${i + 1} / 06`}
                  </p>
                  <h2 className="font-display text-[clamp(4rem,10vw,8rem)] font-bold uppercase leading-none text-white mb-4">
                    {scene.name}
                  </h2>
                  <p className="font-body text-xl text-white/60 mb-8">{scene.count}</p>
                  <a href={sport ? `/sports/${sport.slug}` : '/sports'} className="btn-primary">
                    Explore {scene.name}
                  </a>
                </div>

                {/* Lottie animation — desktop only */}
                <div className="hidden lg:flex justify-center items-center">
                  <div className="w-80 h-80">
                    {/* LottiePlayer dynamically loaded per scene */}
                    <LottieScenePlayer sport={scene.lottie} />
                  </div>
                </div>
              </div>
            </div>
          )
        })}
      </div>
    </div>
  )
}
```

### Mobile Behaviour
The horizontal scroll experience works on mobile — no separate fallback component needed. On small screens, the Lottie column is hidden (`hidden lg:flex`), leaving a clean single-column layout. GSAP ScrollTrigger horizontal scroll works via touch on mobile.

## Lenis + GSAP Integration

Unchanged from the original plan — applies across the whole site.

```tsx
// components/layout/SmoothScrollProvider.tsx
'use client'
import { useEffect } from 'react'
import Lenis from '@studio-freight/lenis'
import { gsap } from 'gsap'
import { ScrollTrigger } from 'gsap/ScrollTrigger'

gsap.registerPlugin(ScrollTrigger)

export function SmoothScrollProvider({ children }: { children: React.ReactNode }) {
  useEffect(() => {
    const lenis = new Lenis({
      duration: 1.2,
      easing: (t) => Math.min(1, 1.001 - Math.pow(2, -10 * t)),
    })

    lenis.on('scroll', ScrollTrigger.update)
    gsap.ticker.add((time) => lenis.raf(time * 1000))
    gsap.ticker.lagSmoothing(0)

    return () => {
      lenis.destroy()
      gsap.ticker.remove((time) => lenis.raf(time * 1000))
    }
  }, [])

  return <>{children}</>
}
```

## Performance Notes

- Video hero: < 8MB compressed MP4. Poster image shows instantly. No render blocking.
- Lottie files: 20–150KB each. Loaded dynamically per page — not in global bundle.
- GSAP ScrollTrigger: ~30KB gzipped. Already in bundle for all other animations.
- Total Phase 3 bundle impact: ~200KB (Lottie + 6 JSON files) vs ~500KB+ (Three.js alone).
